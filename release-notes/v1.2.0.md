Secure Vault 1.2.0 is an interface release. Every screen was rebuilt, the whole
look now comes from a single file you can edit, and a handful of things the app
used to do silently — locking itself, wiping the clipboard, refusing to save —
now say so.

Your vault, backups and settings are untouched by this update. They live in
`%APPDATA%\SecureVault`, and installing over an older version keeps them.

## Changed

- **The interface was rebuilt.** Darker, flatter surfaces, one accent colour,
  and a consistent set of buttons, fields and cards across all eight screens.
- **The look is one file.** Colours, fonts, type sizes, corner radii, spacing
  and the window size come from `UI/palette.json`. Edit it, restart, and the
  whole app follows — no code changes. Put a `palette.json` in
  `%APPDATA%\SecureVault` and it overrides the bundled one, so a scheme you
  like survives updates. A partial file is fine: list only the values you want
  to change.
- **Headings are sentence case** rather than ALL CAPS, and are cased correctly
  per language. Applying title case to translated strings had been producing
  "Generateur De Mots De Passe" in French.
- **Confirmations and errors are in-app panels**, not Windows message boxes —
  deleting an account, restoring a backup, starting a fresh vault, and the
  anti-tampering notices.
- **Settings is organised.** The autofill bridge and the security toggle are
  separate labelled sections, and each explanation sits under the control it
  describes instead of in a block of grey text at the bottom.

## Added

- **Passwords are hidden by default**, everywhere they are shown, with a reveal
  toggle — the account detail screen, the add and edit form, and the three
  fields on the change-master-password screen.
- **Strength is shown where it matters**: creating a vault, changing the master
  password, and saving an account. The generator reports real entropy in bits.
- **Copy a password straight from the list.** Each account row has a copy
  button, so the common case no longer needs opening the account first.
- **The clipboard countdown.** Copied passwords are wiped after 25 seconds;
  the copy button now counts down instead of leaving you to guess.
- **A warning before the idle lock.** The vault locks after five minutes of
  inactivity; you now get 30 seconds' notice, and the login screen says when a
  lock was the reason you are back there.
- **Form validation.** Saving an account with no name, or a name that is
  already taken, says so next to the field rather than doing nothing.
- **The website URL and the date added** appear on the account detail screen.

## Fixed

- The packaged build no longer ships without files it needs at runtime.
