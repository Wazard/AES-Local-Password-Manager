Secure Vault 1.3.0 brings your vault to the iPhone, and makes search find
accounts the way you remember them.

Your vault, backups and settings are untouched by this update. They live in
`%APPDATA%\SecureVault`, and installing over an older version keeps them.

## Added

- **An iPhone app.** It opens the same vault file as the PC — same encryption,
  same master password, same accounts in the same order — with Face ID
  unlock, search, favourites, editing, the password generator and backups.
  It is built as an `.ipa` for sideloading with Sideloadly or AltStore; see
  `ios/README.md`.
- **Send to iPhone.** The new phone icon in the top bar sends your vault to
  the iPhone over your Wi-Fi, with no cloud folder in between. The iPhone
  shows a 6-digit code that has to be typed on the PC, and it asks before it
  replaces anything. What travels is the vault file as it is stored, already
  encrypted with your master password.

## Changed

- **Search understands what you mean.** It looks at the website as well as
  the name and username, and each word you type can match any of them, so
  "amazon outlook" finds the Amazon account on your Outlook address. Case,
  accents and punctuation no longer matter: "luca rossi" finds
  `luca.rossi@…`, and "cafe" finds "Café". Addresses can be typed loosely —
  "luca@outlook" finds `luca.rossi@outlook.it`, and "@outlook" lists every
  account that uses Outlook.
